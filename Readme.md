# Week 2 Weekly Assessment – Task 1: SQL Analysis

## Objective
Perform SQL analysis using PostgreSQL, including joins, aggregations, CTEs, window functions, and JSONB.

## Database
PostgreSQL

## Tables
- customers
- orders
- products

## Analysis Queries
1. Total sales amount per customer using JOIN, GROUP BY, and HAVING.
2. Customers who have never placed an order using LEFT JOIN.
3. Top customer per city using a CTE.
4. Rank orders using ROW_NUMBER() and show previous order amount using LAG().
5. Find Dell products and extract RAM using JSONB operators.

## Files
- `analysis.sql` – SQL table creation, sample data, and analysis queries.
- `screenshots/` – Screenshots of query results.

## How to Run
1. Install PostgreSQL and open pgAdmin 4.
2. Create a database named `week2_assessment`.
3. Open Query Tool.
4. Open and execute `analysis.sql`.
5. Check the query results in Data Output.

## Conclusion
Successfully performed SQL analysis using PostgreSQL joins, aggregations, CTEs, window functions, and JSONB.
